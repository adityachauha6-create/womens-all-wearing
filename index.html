Womens all wearing

Personal media automation application.

About the Application

Womens all wearing is a personal automation application used by its owner to access and organize Pins from the owner's Pinterest account. Selected media may be processed and delivered to a private Telegram group.

Pinterest API

This application uses the Pinterest API to access authorized Pinterest account data. Access is limited to the permissions granted by the account owner.

Privacy

We do not sell or publicly distribute Pinterest account data. Pinterest data is used only for the application's intended media-automation purpose.
